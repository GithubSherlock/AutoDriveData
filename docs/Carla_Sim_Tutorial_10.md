# Carla仿真系列：11_Carla 上帝视角可视化，俯瞰整个仿真世界

前面的教程都在"车里"看世界——相机、雷达、BEV。这期换个视角：跳出车辆，从上帝视角俯瞰整个仿真场景，实时看到所有车辆、行人的位置和运动状态。

## 1 为什么需要上帝视角

自动驾驶开发中，除了"车里的感知"，还经常需要"全局的观察"：

|场景|用途|
| ---- | ---- |
| 调试 | 一眼看清所有NPC跑得对不对 |
| 验证 | 观察算法下车的行为是否符合预期 |
| 讲解/演示 | 观众能直观看到整个场景 |
| 数据采集 | 全局记录车辆轨迹 |

## 2 实现思路

CARLA 仿真环境中自带 OpenDRIVE 高清地图，本期的做法是：

读取并解析 OpenDRIVE 地图（道路/车道/路口）

    ↓
    
解析成几何形状绘制地图可视化（道路、车道线）

    ↓
    
实时获取所有NPC的位置和运动状态

    ↓
    
叠加上帝视角全局画面

核心：不是自己画地图，是解析CARLA自带的高精地图并可视化，再把动态目标叠加上去。

## 3 启动流程

```bash
# 终端1-2：启动环境 + Carla UE4
# 终端3：启动 ROS Bridge
cd carla_sim
bash ros_bridge.sh
# 终端4：创建NPC（让场景动起来）
python scripts/spawn_random_npc_py2.py _vehicle_count:=20 _walker_count:=10
# 终端5：上帝视角可视化
cd /opt/carla_ws/sim_workspace/sim_view
python sim_view_py2.py
```

## 4 核心功能

### 4.1 跟随模式

默认跟随 ego vehicle 运动

| 按键 | 功能 |
| --- | --- |
| F 键 | 切换跟随开关 |
| N 键 | 切换跟随的车辆 ID |

### 4.2 地图操作

| 操作 | 功能 |
| --- | --- |
| 单击拖动 | 平移地图 |
| 滚动 | 缩放地图 |

### 4.3 实时状态显示

实时查看所有 NPC 的位置和运动速度

### 4.4 图形颜色标识

| 图形 | 含义 |
| --- | --- |
| 蓝色方块 | ego vehicle（自车） |
| 红色方块 | NPC 车辆 |
| 绿色方块 | NPC 行人 |
| 三角形 | 交通灯（颜色 = 状态） |

## 5 视觉效果

运行后可以看到：

完整的高精地图（道路、车道、路口）

所有车辆 / 行人以方块形式实时移动

交通灯实时变化（红 / 绿 / 黄）

跟随模式自动追踪自车

这就是一个 "仿真世界监控大屏"—— 整个场景的状态一目了然。
