# Carla仿真系列：13_点云地面提取——把点云里的“地皮“剥掉

第12期建好了点云地图，但地图不是终点，是起点。在实际处理中拿到一帧点云后，第一件麻烦事就是：地面占了点云一大半。地面不处理掉，后面的聚类、分割、目标识别全被它干扰——把车、行人从点云里分出来之前，得先把"地皮"剥干净。这期做地面提取（地面分割）。

## 1 地面提取：通用的三大类方法

先说方法论。这里主要介绍比较通用的地面提取方法，大致可以分三类，各自思路完全不同：

| 流派 | 核心思路 | 代表做法 |
| ---- | ---- | ---- |
| 基于几何规则 | 地面是"平的、实的" | 网格法：分网格统计点云数量/高度，综合判断 |
| 拟合方法 | 地面能被"数学面"描述 | RANSAC 平面拟合；分段拟合适应坡道 |
| 深度学习方法 | 让模型"学会"认地面 | PointNet++、Range Image + 2D卷积（SqueezeSeg）、图像语义分割+点云投影 |

三种方法各有取舍：几何规则快但怕坡道，拟合方法稳但要调参数，深度学习泛化强但算力贵。

## 2 工程落地：三种可跑的方法

这期代码里落地了三种方法，对应三个参数：

```bash
cd /opt/carla_ws/sim_workspace/ground_segmention/build
# 方法0：几何规则（网格法）
./ground_segmention 0
# 方法1：图像语义分割
./ground_segmention 1
# 方法2：先验地图 + RANSAC 迭代
./ground_segmention 2 ./../../pointcloud_map/map/points_map_marker.pcd
```

| 参数 | 方法 | 思路 | 特点 |
| --- | --- | --- | --- |
| 0 | 基于几何规则 | 网格法，在 ROI 区域做地面分割 | 快；只处理感兴趣区域，省算力 |
| 1 | 基于图像语义分割 | 前视相机语义分割结果 + 点云投影位置 | 直观；受 Carla 性能限制，只做效果展示 |
| 2 | 基于先验地图 + RANSAC 迭代 | 用上一期建好的点云地图做先验，RANSAC 迭代精化 | 最稳；结合全局地图约束，坡道也能处理 |

## 4 三种方法的工程细节

### 4.1 0 - 基于几何规则（网格法）

把点云划分成多个网格，统计每个网格内点云的数量、高度最大值和最小值，综合判断这个网格是不是地面。

工程取舍：考虑性能，只在 ROI 区域做地面分割，而不是整片点云全算。速度优先的场景，这是务实的选择。

### 4.2 1 - 基于图像语义分割

深度学习里 "图像语义分割 + 点云投影" 思路的工程版：前视相机做语义分割，点云投影到图像上，投影位置是地面的点，就判为地面点。

工程取舍：受 Carla 性能限制，这里只展示效果，不追求实时。验证思路完全够用。

### 4.3 2 - 基于先验地图 + RANSAC 迭代

这期最推荐的方法：先用上一期建好的点云地图做先验（知道大概哪些区域是地面），再用 RANSAC 迭代拟合地面平面。先验约束 + 迭代精化，比裸 RANSAC 稳得多。

工程取舍：结合全局地图约束，坡道、起伏路面也能拟合出来，是三种方法里最实用的。

## 5 几个要点

- 地面是障碍物感知的 "背景噪声"
  不去掉地面，后面的点云聚类会把地面和障碍物连成一片
- ROI 是性能关键
  几何规则全图跑很慢，圈定 ROI 是工程上的常规优化
- 先验地图是资产
  第 12 期建的地图这期直接变成先验，系列前后是咬合的
- 方法按场景选
  平整场地用网格法就够，复杂地形上 RANSAC + 先验更稳
